# Boabca Recipes

منصة عامة لمشاركة وصفات الأطباق والعصائر وتقييمها.

## التشغيل المحلي
```bash
npm install
npm run dev
```

النسخة الحالية واجهة أولية تعمل محلياً باستخدام localStorage. تسجيل الدخول الحالي تجريبي، ويجب ربط Google OAuth وقاعدة بيانات وتخزين صور قبل الإنتاج.
